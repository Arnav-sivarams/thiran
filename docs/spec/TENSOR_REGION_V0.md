# TH-008 TensorRegion V0 (developer IR)

TensorRegion is a new, deliberately tiny V0 tensor/dataflow DAG extracted from verified typed structured semantic IR after TH-006 ownership/effect qualification. It is neither the legacy Graph, whole-program semantic IR, kernel IR, nor buffer IR. Structured control flow, source binding transitions, imports, calls, state, and effects remain outside this first region boundary.

Each region has a function identity, ordered inputs, one output, and deterministic semantic ValueIds. Nodes retain operation kind, semantic type, known/unknown shape facts, operand dependencies, source span, and attached observable Check metadata where needed. The dump omits source-path and pointer data. The current operations are i64 scalar input/integer, i64 rank-1/2 tensor input/literal, immutable alias, equal-shape tensor Add, and full-rank tensor Index returning i64. Alias is a handle relationship, not an element copy. Tensor Add creates a fresh logical result. Ordered bounds and broadcast checks are attached to their dependent node; runtime access and shape guards retain their observable obligations.

Extraction requires an independently verified semantic Module and successful TH-006 ownership/audit facts. STRICT_NATIVE accepts only an entirely supported straight-line function. Mutation, exceptional access modes, structured control, calls, tuples, copy/move, views, slices, transpose, matmul, reduction, division, imports, RNG, IO, Transfer, and Async are rejected with `BACKEND-UNSUPPORTED`. Known semantically valid broadcasting is rejected as backend incompleteness, never mislabeled `TH-SPEC-BROADCAST`. Unknown equal-shape Add inputs are guarded at runtime; unequal extents use an internal backend-unsupported failure path, not a semantic shape error. No fallback execution path exists.

The independent region verifier rejects duplicate IDs (TRV01), unknown dependencies (TRV02), use before definition (TRV03), invalid Add result (TRV04), Add input mismatch (TRV05), known Add shape mismatch (TRV06), invalid Index input (TRV07), invalid Index scalar result (TRV08), missing output (TRV09), and unsupported/malformed operations admitted as nodes (TRV10). Manually built negative regions exercise all ten. Node order is topological and deterministic; IDs are inherited from semantic expression order, not addresses.

Future checkpoints may enlarge legal extraction, optimize/fuse regions, introduce kernel/loop IR, and schedule devices while preserving the same structured source semantics. This V0 IR is internal and not a serialization or stable compatibility format.
