## Architecture and type table

```text
TH-004 syntax AST -> semantic analyzer -> typed structured module/function/block IR
                  -> independent semantic IR verifier -> exact C++ reference evaluator
```

The module retains source identity, imports (import-containing modules are deferred with an explicit stage diagnostic), declaration-ordered functions, and an internal deterministic top-level initializer block. Function calls are explicit, not compile-time Graph expansion. Tuples remain structured results. Bindings map names to logical ValueIds, not physical buffers; immutable aliasing can reuse a ValueId and emits neither Copy nor Move. SourceSpan remains on instructions, checks, declarations, parameters, and bindings. Checked-failure effect metadata and future effect-class slots exist without claiming a full effect system.

| Semantic type | Representation | TH-005 execution |
| --- | --- | --- |
| `bool`, `i64` | scalar types distinct from rank-0 Tensor | yes (i64 math, bool values) |
| `i32`, `u32`, `u64`, `f32`, `f64` | resolved scalar types | no numerical execution |
| `Tensor<T,R>` | scalar T, rank R in type, extents in ShapeFact | `Tensor<i64,1/2>` only |
| `Buffer<T>` | separate CPU collection type; `u8` byte recognized | no Buffer operations |
| tuples | ordered heterogeneous element types | tuples of executable values |

FunctionIds are declaration-order monotonic starting at 1. Per-block ValueIds begin at 1, parameters first, then deterministic semantic expression/statement construction. No addresses, hashes, time, or randomness enter IDs/dump. Literal tensor shape facts are known, function tensor parameter extents are unknown (`?`), and shape-fact vector length must match rank. The dump prints functions, types, IDs, operations, checks, call targets, shape facts, bindings, and terminators deterministically. It omits source identity so a caller-supplied absolute path cannot enter the dump; source identity remains on diagnostics. Every analyzed fixture is analyzed twice and dump equality is asserted, and an absolute-path probe checks for path omission.

## Semantic contracts and failure policy

Executable operations: checked i64 negation/add/subtract/multiply, rank-1/2 tensor literals, trailing-axis elementwise broadcast, scalar scaling, rank-2 matrix multiplication, zero-based indexing, positive half-open slicing/read-view markers, rank-2 `.T`/read-view marker, constant-axis `sum`, calls, tuple construction/return, and initializer evaluation. Each checked product and accumulation uses pre-operation overflow detection. `/` and `./` remain parsed but receive `TH005-DIVISION-UNSPECIFIED`; no integer rounding rule was invented. Non-`.T` members and dynamic sum axes are rejected. Function signatures are collected before bodies, allowing later-declared calls. Acyclic private omitted results infer deterministically; inference cycles require explicit result signatures, while explicitly typed recursion remains callable.

Known invalid shape/bounds/slice/axis conditions fail statically with `TH-SPEC-*`; unknown extents/indices/bounds emit ordered `Check` IR steps naming kind, operands, selector metadata, SourceSpan, and failure ID. Proven valid cases need no redundant check. Runtime checks execute before the dependent operation. The applicable IDs are `TH-SPEC-I64-OVERFLOW`, `TH-SPEC-BOUNDS`, `TH-SPEC-SHAPE`, `TH-SPEC-BROADCAST`, `TH-SPEC-SLICE`, and `TH-SPEC-AXIS`; they normalize this fixture edition, not future public compiler diagnostic stability. Other analyzer categories are deterministic internal `TH005-*` IDs. Analyzer exceptions are contained by its public result API.

## Limitations and next boundary

Imports are deferred wholesale; no package/cross-file resolution, control flow, generic specialization, public effect spelling, view-lifetime signature, non-i64 exact arithmetic, contextual non-i64 literal conversion, or native backend is claimed. TH-006 owns storage alias/liveness, view escape, exclusive mutation, and memory-safety proof; TH-005 does not start that work. No AD, native CPU/GPU, AOT, JIT, production runtime, or production V0 CLI route exists.
