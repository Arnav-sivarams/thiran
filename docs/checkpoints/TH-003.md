## Oracle architecture and dependency boundary

`tools/spec_oracle.py` is a Python 3 standard-library developer reference outside `src/` and `include/`. `ScalarValue` and `TensorValue` distinguish scalars from rank-1/2 tensors; the latter carry explicit shape and flat row-major elements. The implementation validates extents/element counts, computes offsets and logical coordinates, checks every i64 arithmetic result within `[-9223372036854775808, 9223372036854775807]`, and implements construction, addition/broadcast, indexing, slicing, rank-2 matmul, and one-axis sum. It imports no NumPy, Torch, Triton, Thiran Graph, optimizer, emitter, or runtime. This Python test aid is not a final runtime dependency.

No CTest registration was added. The current `BUILD_TESTING` CMake block requires a selected Python interpreter able to import Torch for existing integration tests. Adding a Python-only oracle test there would couple this independent test to that legacy configuration; direct invocation avoids altering production or test configuration. CMakeLists.txt remains unchanged.

## Canonical result and cases

Fixture schema `thiran-spec-cases-1`, edition `v0-design`, is documented in `docs/spec/CONFORMANCE.md`. Success is a `status: ok`, `kind: scalar/tensor`, `dtype: i64`, and scalar `value` or tensor `shape` plus flat `values`. Checked failure is `status: error` plus semantic `error_id`; Python exception names are not conformance output. IDs: `TH-SPEC-I64-OVERFLOW`, `TH-SPEC-BOUNDS`, `TH-SPEC-SHAPE`, `TH-SPEC-BROADCAST`, `TH-SPEC-SLICE`, and `TH-SPEC-AXIS`. IDs are fixture-schema/edition stable, not an assertion that future public compiler diagnostic taxonomy is frozen.

`tests/spec/v0/cases.json` contains 33 independently frozen expectations across C01–C15:

| Group | Cases | Contract |
| --- | ---: | --- |
| C01–C03 | 5 | scalar signs, both i64 limits, row-major construction |
| C04–C07 | 6 | elementwise/scalar/trailing broadcast, zero-with-one, incompatible broadcast |
| C08–C11 | 9 | index order, bounds, half-open positive slices/mixed rank, invalid slices |
| C12–C13 | 4 | matmul values, product/accumulation overflow, inner-shape failure |
| C14–C15 | 9 | both reduction axes, scalar/empty results, overflow, invalid axes |

Expected values/errors are literal fixture objects, never derived by calling the oracle. The validator compares each independently evaluated actual result to those objects. It refuses malformed schema, duplicate IDs, unknown operations, missing expected fields, mismatches, and zero executed cases.

`tests/spec/v0/ownership_future.json` records OWN-A through OWN-E but is explicitly `executable: false`, `SPEC_DEFINED`, and `COMPILER_NOT_IMPLEMENTED`. Alias without invalidation/deep copy, live-alias mutation rejection, explicit-move invalidation, explicit-copy independence, and borrowed-view lifetime rejection are specification fixtures only.
