## 4. V0.1 SUPPORT MATRIX

`docs/RELEASE_V0_1.md` is the normative matrix. In summary:

- **SUPPORTED / QUALIFIED:** the bounded scalar/tensor source subset,
  indexing/slicing, structured functions/control, ownership, forward Scan,
  native CPU and NVIDIA PTX/Driver TensorRegion paths, accepted async lifetime
  semantics, deterministic planning/fusion, `.tha`, bounded `.thm`, and the
  documented CLI.
- **EXPERIMENTAL:** bounded reverse AD, extension derivatives, reference
  training/`.thc`, numerical graphics, and trusted research extensions.
- **DEFERRED:** recurrent Scan reverse AD, TH-026 portable shipping, proof
  systems, and local intelligence/System-1/ThiranQL.
- **NOT SUPPORTED:** package ecosystem/IDE/LSP, Windows-native/macOS releases,
  sandboxed plugins, signatures, broad GPU portability, and stable-1.0 claims.
