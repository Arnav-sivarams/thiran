# TH-019 — CPU 3D / numerical graphics foundation

Status: implemented; qualification evidence is provided by
`V0GraphicsTests` and the repository regression/sanitizer matrix.

TH-019 introduces `thiran_v0_graphics`, a native C++20 runtime library layered
on TH-007 storage. Its typed entry point accepts f32 position/color/matrix
tensors and i64 indexed triangles, then performs model/view/projection,
six-plane homogeneous clipping, perspective division, viewport mapping,
top-left triangle coverage, strict normalized-depth testing, and
perspective-correct RGBA interpolation. It returns fresh Tensor-backed color
and depth storage and can emit a minimal binary PPM.

The subsystem is intentionally a library/runtime surface. The universal
structured semantic IR remains semantic authority, while TensorRegion remains
the bounded straight-line tensor/dataflow optimization region below it.
Framebuffer mutation and raster traversal stay as structured native loops;
the historical Graph/Region machinery is neither involved nor promoted.

The canonical perspective cube uses eight colored vertices and twelve indexed
triangles with a rotated model, right-handed look-at camera, and perspective
projection. Its frozen same-platform Debug qualification is:

```text
dimensions=96x96
input_triangles=12
post_clip_triangles=12
shaded_pixels=3150
depth_passes=2218
color_digest=fnv1a64:0d0c47343db9df53
depth_digest=fnv1a64:4e244c6d47059a59
```

The graphics suite covers hand-derived identity/translation/scale/rotation,
composition, camera and projection results; malformed cameras and tensors;
all six frustum sides; one/two outside vertices; near/far crossings; clipped
quad fan triangulation; degenerate results; known pixel coverage; shared-edge
quad behavior; strict depth order/equality; perspective-correct and
clipped-vertex colors; repeated deterministic cube output; checked dimensions,
coordinates, indices, non-finite inputs, extreme geometry, `w=0`, zero-sized
frames, and PPM output.

This checkpoint makes no real-time, throughput, or superiority claim. It adds
no graphics syntax, GUI/windowing, scene graph, artifact ABI expansion,
differentiable rasterization, external rendering framework, or GPU rendering.
The complete normative conventions and safety boundary are in
`docs/spec/GRAPHICS_V0.md`.
