## Implemented grammar, AST, and spans

The lexer recognizes ASCII identifiers, decimal integers, future decimal real tokens, quoted import strings, `//` comments, required/reserved keywords, newlines, and the required punctuation/operators. Maximal munch distinguishes `.`, `.*`, `./` and `-`, `->`. The parser handles newline/semicolon statement separation outside literals and row semicolons inside rank-2 tensor literals; newline continuation is allowed inside parentheses/brackets. It parses immutable/mutable `let`, distinct unexecuted function-body `RebindStmt`, expression returns, functions/export, annotated parameters, optional private and required exported result types, tuple result syntax, `Tensor<T,R>`/`Buffer<T>` type syntax, and dedicated imports.

Expression AST variants include identifiers, integer/boolean literals, structural tensor rows, tuples, unary/binary expressions, calls, members, and index expressions. Axes are `IndexSelector(value)` or `SliceSelector(start?, end?, step?)`; omitted bounds are actual empty owned fields. All AST nodes/parameters/types/selectors/diagnostics carry `SourceSpan`, reusing the R12 span shape without sharing its grammar. In a one-file V0 parse, source ID `0` denotes that file; `Module::source` owns its display identity. AST data is value-owned (`std::variant`, vectors, `std::unique_ptr` for recursive edges), not token pointers and not Graph IR. The developer-only `dump()` is deterministic and contains no pointer IDs or absolute paths; it is **not** a public stable serialization format.

The frozen TH-004 syntax precedence is postfix > unary `-` > equal left-associative `*`, `.*`, `/`, `./` > equal left-associative `+`, `-`. Structural tests assert `A + B * C .* D` is `A + ((B * C) .* D)` and `A * B .* C` is `(A * B) .* C`. This is syntax only, not matmul/elementwise typing.

source text -> TH-004 spanned syntax AST
future: AST -> TH-005 typed structured semantic IR -> execution
